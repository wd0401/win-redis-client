# 制作 WinRedis 安装包

本文说明如何把 WinRedis 打成 **单文件 exe**，再进一步生成 **Windows 安装包（Setup.exe）**。

## 1. 发布单文件 exe

在仓库根目录执行：

```powershell
dotnet publish src/WinRedisClient.App/WinRedisClient.App.csproj -c Release -r win-x64 `
  --self-contained true -p:PublishSingleFile=true `
  -p:EnableCompressionInSingleFile=true `
  -p:IncludeNativeLibrariesForSelfExtract=true `
  -o publish/win-x64
```

产物：`publish/win-x64/WinRedisClient.exe`（约 70 MB，自带 .NET 运行时，目标机器无需安装 .NET）。

参数说明：

| 参数 | 作用 |
| --- | --- |
| `-r win-x64` | 目标平台 64 位 Windows |
| `--self-contained true` | 自带运行时 |
| `PublishSingleFile` | 合并为单个 exe |
| `EnableCompressionInSingleFile` | 压缩体积（约减半） |
| `IncludeNativeLibrariesForSelfExtract` | 原生库打包进 exe，首次运行自动解压到临时目录 |

> 不需要单文件时也可以省略后三个参数，得到普通目录发布（体积更大、启动略快）。

## 2. 生成安装包（Inno Setup，推荐）

[Inno Setup](https://jrsoftware.org/isinfo.php) 免费、体积小、脚本简单，适合本类桌面应用。

### 2.1 安装 Inno Setup 6

```powershell
winget install --id JRSoftware.InnoSetup -e
```

或到官网下载安装（默认安装到 `C:\Program Files (x86)\Inno Setup 6`）。

### 2.2 使用仓库内的脚本

脚本：`tools/installer/WinRedis.iss`（已按当前目录结构配置好）：

- 从 `publish/win-x64/WinRedisClient.exe` 取文件
- 按当前用户安装（`PrivilegesRequired=lowest`，无需管理员权限），默认目录 `%LocalAppData%\Programs\WinRedis`
- 创建开始菜单快捷方式，桌面快捷方式可选
- 安装完成后可直接启动
- 卸载不会删除 `%AppData%\WinRedis` 中的连接与设置

命令行构建：

```powershell
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" tools\installer\WinRedis.iss
```

或打开 Inno Setup Compiler → File → Open → 选择 `WinRedis.iss` → Build → Compile。

产物：`publish/installer/WinRedis-1.0.0-win-x64-setup.exe`。

### 2.3 自定义

- 版本号：修改脚本顶部 `#define AppVersion`（与 `WinRedisClient.App.csproj` 中的 `<Version>` 保持一致）
- 安装到 Program Files：`PrivilegesRequired=admin`，`DefaultDirName={autopf}\WinRedis` 自动变为 `C:\Program Files\WinRedis`
- 中文安装界面：Inno Setup 6 自带英文；简体中文需下载 [ChineseSimplified.isl](https://github.com/jrsoftware/issrc/tree/main/Files/Languages/Unofficial) 放到 Inno Setup 的 `Languages` 目录后，在 `[Languages]` 段加入：
  ```
  Name: "chinesesimplified"; MessagesFile: "compiler:Languages\ChineseSimplified.isl"
  ```

### 2.4 代码签名（可选，建议对外分发时执行）

```powershell
signtool sign /fd SHA256 /tr http://timestamp.digicert.com /td SHA256 `
  /a "publish\installer\WinRedis-1.0.0-win-x64-setup.exe"
```

没有证书时 Windows SmartScreen 可能提示"未知发布者"，属于正常现象。

## 3. 便携版 zip（可选）

不想用安装包时，直接压缩发布目录即可：

```powershell
Compress-Archive -Path publish\win-x64\WinRedisClient.exe, README.md, LICENSE `
  -DestinationPath publish\WinRedis-1.0.0-portable-win-x64.zip -Force
```

解压后双击 `WinRedisClient.exe` 运行，数据仍保存在 `%AppData%\WinRedis`。

## 4. 其他打包方案

| 方案 | 适用场景 |
| --- | --- |
| Inno Setup（推荐） | 传统 Setup.exe，脚本简单、体积小 |
| [WiX Toolset](https://wixtoolset.org/) | 需要 MSI、企业批量部署、组策略分发 |
| [MSIX](https://learn.microsoft.com/windows/msix/) | 需要商店/受管分发、自动更新 |
| 单文件 exe 直接分发 | 内部工具、免安装场景 |
